## 🎮 Core Game Mechanics
1. **30-Second Speed Run**: Complete as many dynamic micro-challenges as possible before the clock expires.
2. **Dynamic Scaling Difficulty**: Increases every 3 successful answers with higher speeds, larger grids, and longer sequences.
3. **Score Penalties**: Wrong answers deduct -1 point and reset the combo streak.
4. **6 Addictive Challenge Types**:
   - **Color Reflex**: Stroop effect (mismatched ink vs. text & negation traps).
   - **Visual Eagle Eye**: Spot the subtle odd emoji in high-density grids.
   - **Instant Memory**: Flash memorization of multi-digit numbers for rapid recall.
   - **Speed Tracker**: Radar canvas tracking orbs at varying physics velocities.
   - **Lightning Math**: Split-second arithmetic calculations with decoy answers.
   - **Shape Recognition**: Spot geometric variations in angles, vertices, and rotations.
