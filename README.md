# ⚡ ONLY 1% CAN WIN — Fast Reaction & Brain Challenge

A browser-based reaction, memory, and speed challenge game where players have 30 seconds to solve tricky brain teasers and test if they belong to the top 1% of human brains.

---

## 🎮 Core Gameplay Mechanics
1. **30-Second Speed Run**: Complete as many dynamic micro-challenges as possible before the clock expires.
2. **Dynamic Scaling Difficulty**: After every 3 successful challenges, difficulty increases (larger grids, longer memory sequences, trickier Stroop color traps, faster moving objects).
3. **Score Penalties**: Wrong answers deduct -1 point, break your combo streak, and trigger an error feedback flash.
4. **6 Addictive Challenge Types**:
   - **Color Reflex**: Stroop effect challenge testing word vs. ink mismatch and negation traps.
   - **Visual Eagle Eye**: Spot the subtle odd emoji in a high-density grid.
   - **Instant Memory**: Memorize flashed numeric sequences and recall them in exact order.
   - **Speed Tracker**: Spot and tap the fastest moving orb inside an active radar canvas.
   - **Lightning Math**: Rapid mental arithmetic equations with plausible decoy answers.
   - **Shape Recognition**: Detect the odd geometric shape or flipped orientation.

## 🚀 Viral & Growth Features
- **Performance Rating Tiers**:
  - `0–5`: **Brain Sleeping 😴** (Bottom 40%)
  - `6–10`: **Beginner 🐣** (Top 60%)
  - `11–15`: **Smart Cookie 🍪** (Top 30%)
  - `16–20`: **Genius 🧠** (Top 10%)
  - `21–25`: **Brain Monster 🔥** (Top 3%)
  - `26+`: **Absolute Legend 👑** (**TOP 1% CLUB**)
- **1-Click WhatsApp Sharing**: Pre-formatted viral challenge copy directly sharable to WhatsApp chats and status.
- **Copy Result**: Quick clipboard copy with animated toast feedback.
- **Daily Challenge Mode**: Seeded daily run with daily streak tracking to drive daily active retention.
- **Personal Best Leaderboard**: Saved in `localStorage` tracking all-time high scores, reaction speeds, total accuracy, and run histories.
- **Synthesized Web Audio**: Zero-latency Web Audio API sound effects with pitch-scaling streak chimes, warning countdown pulses, and high-score confetti celebrations.
